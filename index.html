About Me

ข้อมูลส่วนตัวและ เป้าหมายการฝึกงาน

ความมุ่งมั่น แรงบันดาลใจ และสิ่งที่ผมตั้งใจจะเรียนรู้จากการฝึกงานในองค์กรจริง

นักศึกษาไฟแรงที่พร้อมเปิดรับทุกคำแนะนำ

ตลอดระยะเวลาในรั้วมหาวิทยาลัย ผมไม่ได้เรียนรู้เฉพาะทฤษฎีในห้องเรียน แต่ลงมือทำโปรเจกต์จริงนอกเวลาอย่างสม่ำเสมอ การฝึกงานครั้งนี้เปรียบเสมือนก้าวสำคัญที่ผมอยากนำความรู้ด้านการเขียนโค้ดและกระบวนการคิดเชิงตรรกะมาประยุกต์ใช้กับโจทย์ธุรกิจจริง พร้อมรับฟังคำแนะนำจากพี่ๆ ในทีม เพื่อพัฒนาตัวเองให้พร้อมสู่การเป็น Software Engineer มืออาชีพ

นักศึกษาชั้นปีที่ 4 (ICT) Full-Stack & UX/UI พร้อมฝึกงานแบบ Onsite หรือ Hybrid

ทักษะสำคัญ (Key Strengths)

  • ✓ Full-Stack Mindset: เข้าใจภาพรวมทั้งหน้าบ้าน (Frontend), ระบบหลังบ้าน (API) และฐานข้อมูล
  • ✓ UI/UX Sensibility: ออกแบบด้วย Figma ใส่ใจรายละเอียดความสวยงาม ความง่าย และ Usability
  • ✓ Design to Code: แปลงแบบ Prototype ให้เป็นโค้ด Responsive ที่ตรงสเปกและลื่นไหล
  • ✓ Fast Learner: เรียนรู้เทคโนโลยีและเครื่องมือใหม่ๆ ได้ไว พร้อมลงมือปฏิบัติจริง

สิ่งที่อยากเรียนรู้จากการฝึกงาน (Internship Objectives)

มุ่งเน้นการผสานระหว่าง Full-Stack Development และ UX/UI Design เพื่อสร้างดิจิทัลโปรดักต์ที่ทั้งสวยงามและมีประสิทธิภาพ:

  • ✓ Full-Stack Architecture: เรียนรู้กระบวนการพัฒนา Web App แบบครบวงจร ตั้งแต่หน้าบ้าน (Frontend), การเชื่อมต่อ RESTful/GraphQL API, จนถึงการจัดการ Database ในระบบ Production จริง
  • ✓ Design to Code (UX/UI): ศึกษาการนำ Design System จาก Figma มาพัฒนาเป็น UI ที่ใช้งานง่าย สวยงาม ลื่นไหล และคำนึงถึง User Experience กับ Responsive รองรับทุกหน้าจอ
  • ✓ Professional Workflow: สัมผัสการทำงานจริงร่วมกับทีม เช่น กระบวนการ Agile/Scrum, การทำ Code Review, การเขียน Clean Code และการใช้ Git สำหรับทีมขนาดใหญ่
