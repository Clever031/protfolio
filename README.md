# Personal Portfolio - วัชรศักดิ์ สุขทองสา

เว็บไซต์พอร์ตโฟลิโอส่วนตัว (Personal Portfolio) สำหรับยื่นสมัครฝึกงาน ตำแหน่ง **Full-Stack Developer & UX/UI Designer**

---

## 🌟 จุดเด่นของเว็บไซต์ (Features)
- **Modern Dark Aesthetic**: ดีไซน์หรูหราด้วย Glassmorphism, Neon Glow และ Bento Grid Layout
- **Clean & Professional**: ไม่มีอิโมจิ ใช้ไอคอน Vector SVG ระดับพรีเมียม
- **Responsive Web Design**: รองรับการแสดงผลทุกหน้าจอทั้ง คอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน
- **Interactive Capabilities**:
  - Filter หมวดหมู่ผลงาน (Full-Stack, Web App, Academic)
  - ปุ่ม One-Click Copy อีเมลพร้อมแจ้งเตือน Toast Notification
  - ไทม์ไลน์ประวัติการศึกษา (ปวช. -> ปวส. -> ป.ตรี ปี 4)

---

## 🛠️ โครงสร้างไฟล์ (File Structure)
```
portfolio/
├── index.html       # โครงสร้างหน้าเว็บหลัก (HTML5)
├── style.css        # ดีไซน์ซิสเต็มและสไตล์ทั้งหมด (Vanilla CSS)
├── script.js        # ฟังก์ชัน Interactive & Navigation (Modern JS)
├── server.ps1       # สคริปต์รันเซิร์ฟเวอร์จำลองบน localhost:5500
└── README.md        # เอกสารแนะนำโปรเจกต์
```

---

## 🚀 วิธีเปิดใช้งาน (Getting Started)
สามารถเปิดไฟล์ `index.html` บนเบราว์เซอร์ได้โดยตรง หรือรัน Local Server ผ่าน PowerShell:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
แล้วเปิดดูที่ `http://localhost:5500/`
